# iPhone 捷徑自動記帳設定教學

自動記帳分兩步：
1. **捷徑**把文字（Apple Pay 交易、銀行簡訊或截圖辨識）送到資料庫，存成「待確認」紀錄。
2. **打開記帳 App** 時，App 會自動讀出金額和商家、套用你的規則，再轉成正式紀錄。

> 捷徑送出的資料要等你打開 App 才會整理，所以剛付款完立刻打開 App，就會看到「✨ 已自動記帳」。

---

## 事前準備：從 App 取得三個設定值
打開記帳 App → **設定** → **捷徑自動記帳**：

| 設定值 | 是否秘密 | 說明 |
|---|---|---|
| 網址 | 公開 | `https://你的專案.supabase.co/rest/v1/rpc/ingest` |
| apikey | 公開 | `sb_publishable_` 開頭 |
| **token** | 🔐 **秘密** | 按「產生 token」取得，**只會顯示一次** |

🔐 **token 安全須知**
- token 只能「新增待確認紀錄」，**無法讀取**你的任何資料。不過外洩的話，別人可以塞假紀錄進來。
- 不要傳給任何人，也不要貼到對話、記事本或 GitHub。
- **分享捷徑給別人時，token 會跟著被分享出去。** 這幾個捷徑請不要分享。
- 手機遺失、懷疑外洩時：到 App 的 **設定 → 捷徑自動記帳**，按 **撤銷**，再產生新的 token。
- 可以三個捷徑共用一個 token，也可以各用一個（名稱填「Apple Pay」「簡訊」等），之後就能單獨撤銷。

---

## 共用步驟：「取得 URL 內容」動作怎麼設定
三個捷徑最後都用同一個動作把資料送出。在捷徑中加入 **取得 URL 內容**，展開「顯示更多」後這樣填：

| 欄位 | 填入 |
|---|---|
| URL | App 裡的「網址」 |
| 方法 | **POST** |
| 標頭 | 按「新增新標頭」：鍵 `apikey`，值填 App 裡的「apikey」 |
| 要求本文 | **JSON** |
| JSON 欄位 1 | 類型「文字」，鍵 `p_token`，值填你的 **token** |
| JSON 欄位 2 | 類型「文字」，鍵 `p_source`，值依捷徑填 `applepay`／`sms`／`ocr` |
| JSON 欄位 3 | 類型「文字」，鍵 `p_text`，值填要送出的文字（見各捷徑說明） |

成功時會回傳 `{"ok": true, ...}`。如果回傳 `invalid token`，代表 token 填錯或已被撤銷。

## 捷徑 1：Apple Pay 交易（全自動）
需要 iOS 17 以上。用 Apple Pay 付款後會自動送出。

1. 打開 **捷徑** App，點下方的 **自動化**，再點右上角 **＋**。
2. 選 **交易**。
3. **卡片**：選你要自動記帳的卡；**類別**：全選；**商家**：任何商家。
4. 選 **立即執行**，可以關閉「執行時通知」。然後點 **下一步 → 新增空白自動化**。
5. 加入動作 **文字**，內容輸入下面這行。`[ ]` 的部分要點「捷徑輸入」變數，再選對應的屬性：
   ```
   Apple Pay｜卡片：[卡片或票卡]｜商家：[商家]｜金額：[金額]
   ```
6. 加入動作 **取得 URL 內容**，照「共用步驟」設定：
   - `p_source` 填 `applepay`
   - `p_text` 選上一步的 **文字** 變數
7. 點 **完成**。

💡 **對應付款帳戶**：在 App 新增資產帳戶時，把名稱取得和錢包裡的卡片名稱一樣（例如「中信卡」），或在規則裡指定帳戶，App 就會自動扣那個帳戶的餘額。

## 捷徑 2：銀行簡訊（全自動）
收到含有「消費」字樣的簡訊時自動送出。

1. **捷徑 → 自動化 → ＋ → 訊息**。
2. **訊息包含**：輸入 `消費`。如果想只看特定銀行，可以在 **寄件人** 選那家銀行的簡訊號碼。
3. 選 **立即執行**，然後點 **下一步 → 新增空白自動化**。
4. 加入動作 **取得 URL 內容**，照「共用步驟」設定：
   - `p_source` 填 `sms`
   - `p_text` 選 **捷徑輸入**。如果有「內容」屬性，選「內容」。
5. 點 **完成**。

⚠️ **注意事項**
- 只有**手機簡訊或 iMessage** 會觸發。銀行用 LINE 官方帳號或銀行 App 推播發的通知不會觸發，那些請用捷徑 3。
- 每個自動化只能設一個關鍵字。如果某家銀行的簡訊不含「消費」，例如只寫「刷卡」，可以另外建一個自動化，並用 **寄件人** 限定那家銀行。不然同一則簡訊可能觸發兩次，App 會標成「可能重複」，讓你確認。
- 用 Apple Pay 付款時，如果銀行同時發了簡訊，兩邊都會送出資料。App 發現 15 分鐘內有同金額的紀錄時，會標記「⚠️ 可能重複」，讓你確認後刪除其中一筆。

## 捷徑 3：截圖辨識（LINE Pay、銀行 App 推播等）
停在付款完成畫面或通知上時，輕點手機背面兩下就送出。

1. **捷徑** App 下方點 **捷徑 → ＋** 新增捷徑，名稱取「截圖記帳」。
2. 依序加入以下動作：
   1. **拍攝螢幕截圖**
   2. **從影像擷取文字**（影像選上一步的「螢幕截圖」）
   3. **取得 URL 內容**，照「共用步驟」設定：
      - `p_source` 填 `ocr`
      - `p_text` 選 **擷取的文字**
   4. **顯示通知**，內容填「已送出，打開記帳 App 確認」。
3. 設定背面輕點：**設定 → 輔助使用 → 觸控 → 背面輕點 → 點兩下**，選「截圖記帳」。
4. 使用方式：付款完成後，停在 LINE Pay 的「付款完成」畫面，或是把銀行通知下拉展開，然後**輕點手機背面兩下**。

🔐 **隱私提醒**：截圖辨識會把**整個畫面的文字**送進資料庫，存成「原始內容」。請只在付款畫面使用，避免畫面上同時出現其他私人資訊，例如聊天內容或帳戶餘額。

---

## 辨識不出來怎麼辦
- 讀不到金額的紀錄會留在首頁，標示「待確認」。點進去可以看到原始內容，手動填好金額後按儲存。
- **外幣交易**（例如 USD 20.00）會先記下商家和外幣金額，等帳單出來後再手動填台幣金額。
- 如果某家銀行的格式常常辨識失敗，把那則簡訊的格式告訴 Claude，可以加進辨識規則裡。**記得先把卡號、姓名等個資換成假的。**
