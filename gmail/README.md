# Gmail 消費通知自動記帳（Google Apps Script）

Google 的伺服器每 5 分鐘檢查一次你的 Gmail，有新的銀行消費通知信，就把信的**內文**送進記帳 App。整個過程不需要手機開著。

> 建議用**電腦**操作這份教學，Apps Script 的編輯器在手機上很難用。

---

## 🔐 先了解權限與安全性
| 項目 | 說明 |
|---|---|
| 程式在哪裡執行 | 在**你自己的** Google 帳號裡，不經過任何第三方 |
| Gmail 權限 | **唯讀**（`gmail.readonly`），程式不能寄信、刪信或修改信件 |
| 讀哪些信 | 只讀符合 `QUERY` 條件的信，預設是富邦「即時消費通知」與國泰世華「消費彙整通知」 |
| 送出什麼 | 只送出那封信的**內文**，不送寄件人、收件人或其他信件 |
| token 存在哪 | Apps Script 的「指令碼屬性」，只有你看得到；程式碼裡沒有任何秘密 |

⚠️ **不要分享這個 Apps Script 專案**，也不要把它設為共用。有編輯權限的人可以看到 token。

---

## 步驟 1：資料庫更新
在 Supabase 的 SQL Editor 執行 `supabase/migrations/004_email_source.sql`，新增「Email」來源。

## 步驟 2：產生專用 token
記帳 App → **設定**，往下捲到 **捷徑自動記帳** 卡片的「② 捷徑專用 token」：
1. 「用途名稱」欄位改成 `Gmail`，按 **🔑 產生新的 token**。
2. 複製 token，**先不要關掉這個畫面**，步驟 5 會用到。

Gmail 用專屬的 token，以後可以單獨撤銷，不會影響捷徑。

## 步驟 3：確認寄件者網域（預設已含富邦 `taipeifubon.com.tw`、國泰 `cathaybk.com.tw`）
在 Gmail 打開一封富邦的消費通知信，點寄件者名稱，看完整的 Email 地址：
- 如果結尾是 `@taipeifubon.com.tw`：不用改。
- 如果是別的網域：步驟 4 時，把 `Code.gs` 最上面 `QUERY` 裡的 `taipeifubon.com.tw` 換成那個網域。

## 步驟 4：建立 Apps Script 專案
1. 打開 https://script.google.com ，按 **新專案**。左上角把名稱改成「記帳 Gmail」。
2. 左側點 **⚙️ 專案設定**，勾選 **在編輯器中顯示「appsscript.json」資訊清單檔案**。
3. 回到左側 **‹› 編輯器**：
   - 點 `appsscript.json`，**刪掉全部內容**，貼上 repo 裡 [`gmail/appsscript.json`](appsscript.json) 的內容。
   - 點 `程式碼.gs`（或 `Code.gs`），**刪掉全部內容**，貼上 repo 裡 [`gmail/Code.gs`](Code.gs) 的內容。
   - 按 **💾 儲存**。

## 步驟 5：設定指令碼屬性
左側 **⚙️ 專案設定**，捲到最下面的 **指令碼屬性**，按 **新增指令碼屬性**，新增以下三個：

| 屬性 | 值 |
|---|---|
| `INGEST_URL` | 在記帳 App「① 捷徑要填的設定值」的**網址**那一列按「複製」（⚠️ 不要複製這份教學裡的文字） |
| `APIKEY` | 在記帳 App 的 **apikey** 那一列按「複製」（`sb_publishable_` 開頭） |
| `TOKEN` | 步驟 2 的 token |

按 **儲存指令碼屬性**。現在可以回 App 按「我已經貼到捷徑了」。

## 步驟 6：試跑並授權
1. 回到 **編輯器**，上方函式選單選 `dryRun`，按 **▶ 執行**。
2. 第一次執行會要求授權：
   1. 按 **審查權限**，選你的 Google 帳號。
   2. 會出現「**Google 尚未驗證這個應用程式**」。這是正常的，因為這是你自己寫的程式，沒有送 Google 審查。按左下角 **進階 → 前往「記帳 Gmail」（不安全）**。
   3. **確認權限只有以下三項**，再按 **允許**：
      - 查看您的電子郵件訊息和設定（唯讀）
      - 連線至外部服務
      - 允許這個應用程式在您不在時執行
   4. 如果出現其他權限，例如「讀取、撰寫、傳送及永久刪除…」，**請不要允許**，並回報給 Claude。
3. 下方的執行紀錄會列出最近 7 天符合條件的信件和內文開頭，確認抓到的是消費通知信。**這一步不會送出任何資料。**

## 步驟 7：啟動
函式選單選 `setup`，按 **▶ 執行**。看到「✅ 設定完成」就完成了。

之後收到的消費通知信會在 5 分鐘內送進記帳 App，下次打開 App 時就會自動記帳。
`setup` 只會處理**之後**收到的信。在這之前的消費，請自己手動補記。

## 日常管理
| 想做的事 | 怎麼做 |
|---|---|
| 暫停自動記帳 | 執行 `stop` |
| 恢復 | 執行 `setup` |
| 看執行紀錄 | 左側 **≡ 執行作業** |
| 新增其他銀行 | 在 `QUERY` 用 `OR` 加上條件，例如 `(from:taipeifubon.com.tw "即時消費通知") OR (from:銀行網域 "消費通知")`。把信件格式（遮掉個資）給 Claude，確認辨識得出來 |
| 撤銷 Google 權限 | https://myaccount.google.com/permissions → 「記帳 Gmail」→ 移除存取權 |
| token 外洩 | 在 App 撤銷 Gmail token，產生新的，再更新指令碼屬性 `TOKEN` |

## 分類小技巧
國泰的信會附「消費類別」（例如：餐飲）。如果你的 App 裡有**同名的分類**，沒有規則符合時會自動歸到那個分類。

## ⚠️ 避免重複記帳
富邦的信和 LINE Pay 截圖會是同一筆消費。接上 Gmail 之後，**綁富邦卡的 LINE Pay 就不用再截圖了**。如果兩邊都送了，App 會標記「可能重複」，請你刪掉其中一筆。
